# CSPB-2270-Data-Structs-Sudoku-Final

Final Project for 2270 Data Structures: An exploration of Sudoku

## Build & run

From the project root, configure an out-of-source build in `build/`, compile the `hello` executable, then run it.

**One line (copy everything below):**

```sh
cmake -S . -B build && cmake --build build && ./build/hello
```

- `cmake -S . -B build` — generates build files under `build/`
- `cmake --build build` — compiles the project
- `./build/hello` — runs the binary (macOS/Linux)

**Individually:**

```sh
cmake -S . -B build
```

```sh
cmake --build build
```

```sh
./build/hello
```
